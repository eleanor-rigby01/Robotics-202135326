# 2026년 11월 15일 실습

### 실습 내용
버튼과 가변저항의 입력값을 읽고, LED·부저·서보모터를 제어해 보았다.

### 관련 이론
- **GPIO:** 디지털 핀으로 버튼의 상태를 읽거나 LED를 제어한다.
- **풀업/풀다운:** 버튼을 누르지 않았을 때 입력값이 불안정해지는 것을 막아 준다.
- **ADC:** 아날로그 전압을 숫자로 바꾼다. Arduino Uno는 기본적으로 0~1023, ESP32 실습에서는 대략 0~4095 범위를 사용했다.
- **시리얼 통신:** `Serial.println()`으로 값을 확인하며, 사용한 코드의 통신 속도는 115200 baud이다.
- **PWM:** 신호가 켜져 있는 시간의 비율을 바꿔 LED 밝기나 부저 출력을 조절할 수 있다.
- **서보모터:** 제어 펄스의 폭에 따라 목표 각도가 정해진다.

### 실습 과정 및 결과

**1. 버튼 입력 (`button_code.txt`)**  
2번 핀의 버튼 상태를 `digitalRead()`로 읽었다. 버튼을 누르면 `Pressed`, 떼면 `Not Pressed`가 시리얼 모니터에 출력되었다.

**2. 버튼으로 LED 제어 (`button_led_code.txt`)**  
버튼은 2번 핀, LED는 7번 핀에 연결했다. 버튼을 누르면 LED가 켜지고 떼면 꺼졌다.

**3. 가변저항으로 LED 밝기 조절 (`potentiometer.txt`)**  
A2 핀에서 값을 읽고 `map()`으로 0~255 범위로 바꾼 뒤 9번 핀에 출력했다. 가변저항을 돌리자 LED 밝기가 달라졌다.

**4. 가변저항 값 출력 (`potentiometer.ino`)**  
ESP32의 39번 핀에서 가변저항 값을 읽어 시리얼 모니터에 출력했다. 가변저항을 돌릴 때 숫자가 변했다.

**5. 부저 제어 (`buzzer.ino`)**  
ESP32의 5번 핀에 PWM을 설정하고 출력값을 `32 → 64 → 128 → 0`으로 바꿨다. 부저가 작동했으며 0으로 설정하면 소리가 멈췄다.

**6. 서보모터 제어 (`servo.ino`)**  
ESP32의 14번 핀에 서보모터를 연결하고 0~180도, 다시 180~0도의 각도 명령을 반복했다. 서보모터가 제어 신호에 반응하는 것을 확인했다.

**7. 가변저항으로 서보모터 제어 (`potentiometer_servo.ino`)**  
39번 핀의 입력값을 `map()`으로 각도로 바꿔 14번 핀의 서보모터에 전달했다. 가변저항을 돌리면 서보모터 각도가 변했다.

### 실행 방법 및 참고 사항
- `.txt` 파일은 Tinkercad의 Arduino Uno 회로에 코드를 입력하고 시뮬레이션을 실행한다.
- `.ino` 파일은 ESP32용으로, Arduino IDE에서 ESP32 보드와 포트를 선택해 업로드한다.
- 서보모터 코드에는 `ESP32Servo` 라이브러리가 필요하다. 부저 코드는 ESP32의 `ledcAttach()`를 지원하는 환경에서 실행한다.
- 시리얼 모니터는 **115200 baud**로 설정한다. 회로 연결 시 전원과 GND도 확인한다.

### 실습 정리
버튼은 두 가지 상태로 입력을 구분하고, 가변저항은 연속적으로 변하는 값을 읽는다는 차이를 확인했다. 입력값으로 LED 밝기와 모터 각도를 조절할 수 있었다.
