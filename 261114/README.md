# 2026년 11월 14일 실습

### 실습 내용
Tinkercad에서 아두이노와 LED를 연결하고, 코드로 LED를 깜빡이게 해 보았다.

- **관련 이론:** GPIO는 핀을 입력이나 출력으로 사용하는 기능이다. `HIGH`와 `LOW`로 LED를 켜고 끌 수 있고, 저항은 LED에 과도한 전류가 흐르는 것을 막아 준다. (옴의 법칙: `V = IR`)
- **과정:** LED를 7번 핀에 연결하고 `digitalWrite()`와 `delay()`를 사용했다.
- **결과:** LED가 1초 켜지고 1초 꺼지는 동작을 반복했다.
- **코드:** `ledcode.txt`

**실행 방법:** Tinkercad Circuits에서 7번 핀에 LED와 전류 제한 저항을 연결하고, `ledcode.txt`를 입력한 뒤 시뮬레이션을 시작한다.
